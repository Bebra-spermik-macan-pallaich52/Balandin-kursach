# Анализ документации и границы работы

## Основание

Пользователь задал конкретный объем: первая часть REST-сервиса на FastAPI — создание
ORM-модели и миграция БД. Упомянутое отдельное фото с этапами среди пяти вложений отсутствует.
В «Баландин.pdf» есть примеры интерфейсов, но нет списка этапов ORM-разработки. Поэтому
границы поставки определены по тексту запроса, без предположений о содержании фото.

В общей методичке указан размер шрифта 12 пт (PDF, с. 21), в отдельном документе правил —
14 пт. Для прилагаемой краткой записки выбран специализированный документ правил: 14 пт.
Рамки и ведомость итогового проекта не заполнялись: пользователь запросил программный
этап, номер студенческого и окончательная группа (в ТЗ указано «ИП-41/ИП-41к») не определены.

В шаблоне рамок приведены примеры источников по WPF/C#. Это содержимое шаблона,
а не требование заменить явно запрошенный стек FastAPI.

## Матрица готовности

| Требование | Реализация этого этапа | Продолжение |
|---|---|---|
| Сотрудники и распределение по отделам | Employee, Department, FK | CRUD и фильтрация по полномочиям |
| Личные документы и контакты | EmployeePersonalData, поля Employee | Валидация запросов и контроль доступа к личным данным |
| Четыре типа пользователей | Role и User, справочник ролей в миграции | JWT и проверки разрешений |
| Назначение производственных задач | Task.assignee_id, Task.department_id, Task.created_by_id | Сервис назначения и проверки области доступа |
| Фиксация выполнения | completed_at, completed_by_id и CHECK согласованности | Авторизованная операция подтверждения |
| Kanban и просрочка | Состояния и вычисляемый Task.is_overdue | Маршруты доски и фильтры |
| Отчеты за месяц/год | Сроки, фактическое выполнение, исполнитель и история | Агрегации, диаграммы, Word/Excel |
| Поиск по фамилии с опечатками | Фамилия хранится отдельно, есть индекс lower(last_name) | Реальный нечеткий поиск и специализированный индекс, например pg_trgm |
| ORM и миграции | Восемь SQLAlchemy-моделей, две Alembic-ревизии | Новые ревизии по мере развития |
| Django | Данные и REST-основа подготовлены | Самостоятельный следующий этап |

Наличие роли в таблице не означает реализацию авторизации. Наличие индекса lower(last_name)
не означает реализацию нечеткого поиска. Эти возможности сейчас не заявляются как готовые.

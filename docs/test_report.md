# Проверка этапа 1

Дата: 02.11.2026. Среда: Linux, Python 3.12.14, PostgreSQL 17 (официальный образ
`postgres:17-bookworm`), SQLAlchemy 2.0.55, Alembic 1.20.1, FastAPI 0.162.0.
Тесты выполнены на настоящей PostgreSQL через psycopg, не на SQLite и не на подмене ORM.

## План

Цель — подтвердить воспроизводимость схемы, целостность данных и запуск основы REST-сервиса.
Перед тестами формируется пустая отдельная схема PostgreSQL. Каждый тест применяет
миграции; после теста схема удаляется. Критерий завершения — все проверки проходят,
Alembic не находит различий, приложение отвечает на служебные запросы.

Тесты были сформированы до реализации моделей: первичная проверка сбора тестов завершалась
`ModuleNotFoundError: No module named 'app'`. Затем реализованы модели и миграции,
исправлены обнаруженные проблемы и выполнен зеленый прогон. Это цикл red/green/refactor
для текущего этапа; тестирование будущего CRUD и Django сюда не включено.

```bash
python -m pytest -q --junitxml=docs/test-results.xml --cov=app --cov=scripts.seed_demo \
  --cov-report=term-missing --cov-report=json:docs/coverage.json
ruff check .
alembic check
```
